🔟.2 Как напоминать про LESSONS_LEARNED.yaml
Лучший способ: Добавить в системный промпт для всех агентов:

"Перед началом работы обязательно загрузи LESSONS_LEARNED.yaml. Проанализируй все ошибки из этого файла и убедись, что не повторяешь их. Если сомневаешься — спроси у пользователя."

Технически: Можно автоматически загружать файл в контекст каждого запроса к ИИ.

1️⃣1️⃣ Как автоматически проверять галлюцинации
Решение:

Добавить валидацию — проверять результаты на соответствие структуре (Pydantic-схемы)

Добавить санитизацию — очищать вывод от невалидных данных

Двойная проверка — отправлять один и тот же запрос дважды, сравнивать ответы

Использовать меньшие модели — они реже галлюцинируют

1️⃣2️⃣ Чёткие критерии "готово"
Пример:

yaml
Definition of Done для FileReader:
- [ ] Все файлы сканируются асинхронно
- [ ] Поддерживаются .py, .js, .ipynb
- [ ] Есть прогресс-бар
- [ ] Статистика по расширениям
- [ ] Тесты проходят (покрытие >80%)
- [ ] Документация обновлена

1️⃣3️⃣ Как убрать додумывания
Золотое правило: "НЕ домысливать — лучше спросить и уточнить!"

Технически:

Чёткие промты — без двусмысленностей

Запрет на предположения — "если не знаешь — спроси"

Проверка фактов — всегда ссылаться на исходный код

1️⃣4️⃣ Как обновлять память
Способ: Каждые 500 строк кода или после каждого завершённого агента.

Промт для обновления:

"Подведи итог текущего этапа. Перечисли, что сделано, что осталось, какие проблемы возникли. Запиши это в контекст для следующего агента."

1️⃣6️⃣ Когда спрашивать "мы на правильном пути"
Ситуации:

После завершения каждого агента

При нестандартном поведении (ошибки, предупреждения)

При изменении архитектуры

Если задача занимает >1 дня

Промт:

"Мы закончили этап {название}. Подтверди, что мы на правильном пути, и укажи следующие шаги."


2️⃣2️⃣ Как свести к минимуму галлюцинации
План:

Чёткие промты — без двусмысленностей

Валидация — проверять вывод на соответствие схеме

Двойная проверка — повторять запрос, сравнивать ответы

Контекст — загружать LESSONS_LEARNED.yaml перед каждой задачей

Спринты по 1-2 дня — разбивать на мелкие задачи
