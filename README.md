# 🧠 LocalMind AI-Agent

**LocalMind** — это мощный AI-агент для анализа кодовой базы и генерации интерактивных mindmap. Он автоматически сканирует папки с проектами, извлекает сущности (классы, функции, импорты) и визуализирует их в виде красивой интерактивной карты.

![Пример карты проекта](mindmap_example.png)

---

## ✨ Возможности

- 🔍 **Глубокий анализ кода** — извлекает классы, функции, импорты из Python и JavaScript файлов
- 📊 **Интерактивные mindmap** — цветовая кодировка, масштабирование, поиск
- 🚀 **Асинхронная обработка** — быстро сканирует большие проекты
- 🎨 **Красивый CLI** — прогресс-бар и цветной вывод через `rich`
- 📦 **Модульная архитектура** — легко добавлять поддержку новых языков
- 🧠 **Готов к интеграции с AI** — можно подключить Ollama для глубокого анализа

🚀 Пошаговая инструкция для пользователей
Подготовка:

Установить Python 3.10+:
python --version  # Должно быть 3.10 или выше

Установить зависимости:
pip install -r requirements.txt

Установить проект:
pip install -e .

Запуск CLI:
# Анализ проекта
localmind /path/to/project

# Сохранение в файл
localmind /path/to/project --output map.html

# Ограничение количества файлов
localmind /path/to/project --max-files 50

Запуск веб-интерфейса:
python -m app.web

Открыть в браузере: http://localhost:8000
или
Открыть в браузере: http://127.0.0.1:8000


2️⃣3️⃣ CLI-инструмент
Как работает:
localmind /path/to/project

1. Сканирует папку
2. Анализирует код
3. Генерирует mindmap.html
4. Выводит статистику в консоль

Для автоматизации:
localmind /path/to/project --output map.html --max-files 100
Можно использовать в CI/CD.


Использование веб-интерфейса:
1. Загрузить ZIP-архив или указать путь к папке
2. Нажать "Анализировать"
3. Дождаться результата
4. Просмотреть mindmap
5. Скачать HTML или PDF

Что вы увидите:
📊 Статистика — файлы, строки, сущности
📂 Расширения — какие файлы найдены
🔒 Целостность кода — зелёный/жёлтый/красный статус
🗺️ Интерактивная mindmap — визуализация структуры
