## 5. Проверяем, что установка прошла

```bash
localmind --help
```

Должно показаться:

```
usage: localmind [-h] [-o OUTPUT] [-m MAX_FILES] [-v] path

LocalMind — AI-агент для анализа кода и генерации mindmap

positional arguments:
  path                  Путь к папке с проектом для анализа

options:
  -h, --help            show this help message and exit
  -o OUTPUT, --output OUTPUT
                        Путь для сохранения HTML-карты (по умолчанию: mindmap.html)
  -m MAX_FILES, --max-files MAX_FILES
                        Максимальное количество файлов для анализа (0 = без ограничений)
  -v, --version         show program's version number and exit

Примеры:
  localmind analyze ./my_project
  localmind analyze ./my_project --output map.html
  localmind analyze ./my_project --max-files 50
```

## 6. Теперь ты можешь анализировать ЛЮБОЙ проект

```bash
# Анализировать любой проект на диске
localmind analyze "C:/Users/User/Desktop/MyProject"

# Анализировать текущую папку
localmind analyze .

# Сохранить результат в другой файл
localmind analyze ./my_project --output my_map.html

# Ограничить количество файлов (для больших проектов)
localmind analyze ./my_project --max-files 100
```

## 7. Если хочешь поделиться проектом

1. Инициализируй Git:
```bash
git init
git add .
git commit -m "First commit: LocalMind AI-Agent"
```

2. Создай репозиторий на GitHub.
3. Запушь:
```bash
git remote add origin https://github.com/your-username/localmind.git
git push -u origin main
```

Теперь другие люди смогут установить твой инструмент одной командой:
```bash
pip install git+https://github.com/your-username/localmind.git
```
