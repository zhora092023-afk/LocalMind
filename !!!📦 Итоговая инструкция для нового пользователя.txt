📦 Итоговая инструкция для нового пользователя

Шаг 1: Скачай и распакуй проект
Скачай архив localmind.zip

Распакуй в любую папку, например:
C:\Users\Имя_пользователя\Desktop\localmind

Шаг 2: Установи Python (если не установлен)
Скачай Python с https://python.org
Установи, обязательно поставив галочку:
✅ "Add Python to PATH"
Проверь установку: открой PowerShell и выполни:
python --version
Должно показать Python 3.10+

Шаг 3: Установи программу (ОДИН РАЗ)
Открой PowerShell в папке с проектом и выполни:
pip install -e .
Это установит все зависимости и сделает программу доступной.

Шаг 4: Запуск через файл "start_localmind.bat" для запуска одним кликом (достаточно дважды кликнуть)

Шаг 5: Запуск через ярлык на рабочем столе:
Создай ярлык на start_localmind.bat
Перенеси ярлык на Рабочий стол
Теперь один клик по ярлыку запускает программу!

Шаг 6: Что происходит после запуска
Открывается командное окно (чёрное) с логами
Автоматически открывается браузер с адресом http://127.0.0.1:8000
Ты видишь веб-интерфейс LocalMind

Шаг 7: Как пользоваться
Через веб-интерфейс:
Укажи путь к папке с проектом:
C:\Users\Имя_пользователя\Desktop\мой_проект
Нажми "Анализировать"
Дождись результата
Открой mindmap.html или скачай PDF

Шаг 8: Как остановить программу
Закрой вкладку браузера
В чёрном окне нажми Ctrl+C
На вопрос "Завершить пакетный файл?" нажми Y и Enter

🚀 Альтернатива: Использовать localmind через командную строку
Для опытных пользователей:

# Перейти в папку с проектом
cd C:\Users\Имя_пользователя\Desktop\localmind

# Проанализировать проект
localmind C:\Users\Имя_пользователя\Desktop\мой_проект


🛠️ Дополнительно: Создан файл "localmind_cli.bat" для CLI-запуска (теперь можно анализировать любой проект, просто введя путь).

🔥 Бонус: Запуск с автозагрузкой (для продвинутых)
Если нужно, чтобы программа запускалась автоматически при включении компьютера:

Нажми Win+R, введите shell:startup

Скопируй ярлык start_localmind.bat в открывшуюся папку

Теперь LocalMind будет запускаться при старте Windows!
